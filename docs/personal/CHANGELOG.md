# Personal Changelog

## v1.4.0 · Windows 离线版与双向同步

- 新增复用现有个人版界面的 Windows x64 APP；本地 FastAPI 与 SQLite 支持库存、项目、EDA、标签和文件在断网状态下完整读写。
- APP 首次登录通过账号中心设备授权自动从服务器 API 下载个人数据及附件，不要求用户在浏览器手动导出或导入数据包。
- 联网后按服务器游标增量双向同步，并提供字段时间合并、库存增量事件、删除墓碑、附件续传和冲突处理中心。
- 新增 `cwbackup/v2` 完整灾备包，保存一致性数据库快照、有效附件、SHA256 清单，并支持校验、暂存、回滚式恢复。
- 网页端仅提供 Windows 安装包下载入口；团队、账号安全、AI 与 Codex 功能仍为在线专属。

## v1.3.0 · Project V2 全量重建

- 个人项目只保留 `/projects` 一个入口；旧仪表盘、数字 ID 详情页和公开项目页已从前端源码移除。
- 项目总览与工作区在同一页面切换，提供状态、周成本、费用构成、响应式项目表格以及五个清晰工作区。
- 新项目默认建立空 V1；支持版本 BOM、BOM 文件导入、多块实物板、逐焊点焊接/报损、材料成本快照、费用、文件和风险。
- 上线迁移会先备份 SQLite，再清理全部既有个人项目；库存数量和历史库存流水不反向恢复，团队项目不受影响。
- ChatGPT 查询和网页审批写入已切换到 Project V2；项目编号建立后保持稳定，不再提供编号修改和旧编号别名。

## v1.2.3 · 高对比配色与稳定加载态

- 主文字、次要文字和主操作色在白色卡片上均达到 WCAG AA 及以上对比度。
- 修复共享卡片背景覆盖项目深色侧栏和项目头部的样式级联问题。
- 首屏、身份验证和局部读取统一使用浅色背景与石油蓝加载器，不再压暗或洗白页面。

## v1.2.2 · 矿物材质视觉与信息减负

- 首页收敛为 4 个主指标、轻量上下文条、主要分类和折叠异常清单，减少同权重数据造成的拥挤。
- 项目总览与详情页统一卡片间距、导航、图表、看板和表格，并增加文字截断与窄屏横向安全区。
- 全局换用矿物青、陶瓷白、氧化铜与鼠尾草配色，使用静态 CSS 材质而不使用重型模糊效果。
- 首页折叠下方内容延迟渲染，项目图表改为按需注册 ECharts 模块。

## v1.2.0 · 项目全链路与成本

- `/projects` 升级为项目仪表盘，提供状态看板、周成本趋势、状态分布、筛选排序和轻量分页表格。
- 项目编号全局唯一并保留历史别名；状态变更、起止日期、ISO 周、归档与恢复均可追溯。
- 每个项目拥有独立 PCB 版本链；V2 默认继承上一版 BOM，但不复制实物板、焊接状态、成本、制造文件或库存动作。
- 新增焊接/报损时点均价快照、未计价补齐、费用台账、版本成本差异和采购金额防重复计费。
- ChatGPT 继续通过待网页审批单执行写入，文件上传仍只在网页端完成。

## v1.1.0 · Gerber 可视化装配

- 项目页收敛为装配工作台、BOM/匹配、采购与风险、文件版本四个工作区。
- 支持上传 Gerber ZIP + BOM + CPL，预览并确认后按“板面 + 位号”精确关联现有 BOM 和焊接历史。
- 支持顶底面、图层开关、拖动缩放、清单/画布双向定位、校准、未定位托盘、批量实物板和快捷键。
- 报损改为可累计事件；焊接、撤焊、报损、撤销报损和最近操作撤销均使用原子库存事务。
- 公开装配简图默认关闭，开启后只提供脱敏只读几何和进度。

## Open-source profile

- Uses local username/password accounts by default.
- Uses generic branding and no bundled private logo by default.
- Keeps component inventory, stock batches, projects, BOM matching, purchases, risks, labels, and scan pages.
- Excludes private deployment data, filing numbers, secrets, and brand assets.
